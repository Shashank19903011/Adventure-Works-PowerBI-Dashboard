# 📂 Datasets

## Overview

This folder contains the datasets used to build the **Adventure Works Sales Dashboard** in Power BI.

These datasets were used for data modeling, transformation, DAX calculations, and dashboard creation.

---

## Dataset Files

| Dataset | Description |
|----------|-------------|
| AdventureWorks Calendar Lookup.csv | Date dimension used for time-based analysis. |
| AdventureWorks Product Categories Lookup.csv | Product category information. |
| AdventureWorks Product Lookup.csv | Product details including product names and attributes. |
| AdventureWorks Product Subcategories Lookup.csv | Product subcategory information. |
| AdventureWorks Returns Data.csv | Product return transactions and return analysis. |
| AdventureWorks Sales Data 2020.csv | Sales transactions for the year 2020. |
| AdventureWorks Sales Data 2021.csv | Sales transactions for the year 2021. |
| AdventureWorks Sales Data 2022.csv | Sales transactions for the year 2022. |
| AdventureWorks Territory Lookup.csv | Sales territory and regional information. |

---

## Data Model

The dashboard uses a star schema with:

- Calendar Lookup
- Product Lookup
- Product Categories
- Product Subcategories
- Territory Lookup

These lookup tables are connected with:

- Sales Data (2020–2022)
- Returns Data
